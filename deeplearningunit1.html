01 · The building block

A single neuron

Every deep network is millions of copies of one tiny unit: multiply each input by a weight, add a bias, then squash the sum through an activation function. Move the sliders and watch the neuron's decision line tilt.

Inputs & parameters

the neuron fires (bright) on one side of its line, stays quiet on the other · ● = your input point
How it works, step by step
  1. Weighted sum. The neuron multiplies each input by a weight and adds a bias: z = w₁x₁ + w₂x₂ + b Weights say how much each input matters; the bias shifts the threshold.
  2. Activation. The sum is passed through a non-linear function a = f(z) that decides how strongly the neuron "fires". Without it, stacking neurons would still only draw straight lines.
  3. A decision line. For two inputs, the set of points where z = 0 is a straight line; the neuron outputs high on one side and low on the other. The weights rotate that line, the bias slides it.
  4. Scaling up. Connect many neurons in layers and you can bend those lines into arbitrarily complex decision boundaries — that's a deep network.
02 · Non-linearity

Activation functions

The squashing function is what lets networks learn curves, not just lines. Compare the classics — and see each one's derivative, which is what back-propagation actually uses.

Function

solid = f(x) · dashed = f′(x) the gradient · ● = current input
How it works, step by step
  1. Sigmoid σ(x)=1/(1+e⁻ˣ) squashes to (0,1) — nice as a probability, but its gradient nearly vanishes for large |x| (saturation), which slows deep training.
  2. Tanh is a rescaled sigmoid to (−1,1), zero-centred, but still saturates.
  3. ReLU max(0,x) is the deep-learning workhorse: no saturation for x>0 and trivially cheap. Its gradient is just 0 or 1. Risk: a unit stuck at 0 forever (a "dead" ReLU).
  4. Leaky ReLU lets a small slope through for x<0, curing dead units.
  5. Softmax turns a whole vector of scores into probabilities that sum to 1 — used at the output of a classifier. Drag the three logits to see the competition.
03 · Deep feedforward network

The forward pass

Stack neurons into layers and information flows left to right: each layer's outputs become the next layer's inputs. Set the inputs and watch activations light up through a 2 → 4 → 3 → 1 network.

Inputs

node brightness = activation · edge colour = weight (violet +, pink −), thickness = magnitude
How it works, step by step
  1. Layer by layer. Each neuron in a layer computes its weighted sum of the previous layer's outputs plus a bias, then applies its activation. In matrix form: a⁽ˡ⁾ = f(W⁽ˡ⁾ a⁽ˡ⁻¹⁾ + b⁽ˡ⁾)
  2. Depth builds abstraction. Early layers detect simple patterns; later layers combine them into complex ones. "Deep" just means many such layers.
  3. One direction. In a feedforward net the data never loops back — inputs to outputs in a single sweep. That sweep is the "forward pass".
  4. Then we score it. The final output is compared to the target by a loss function (tab 05), and the error is sent backwards to improve the weights (tab 06).
04 · Why we need hidden layers

Learning XOR

XOR (output 1 when the inputs differ) famously cannot be solved by a single neuron — no straight line separates the classes. Add one hidden layer and press Train to watch gradient descent bend the boundary until it works.

Model & training

decision surface · ○ class 0 · ● class 1
training loss over steps
How it works, step by step
  1. The problem. XOR outputs 1 for (0,1) and (1,0), but 0 for (0,0) and (1,1). Plot those four points: no single straight line can put the two 1's on one side and the two 0's on the other.
  2. Why one neuron fails. A single neuron only draws one line, so it gets stuck around 50–75% accuracy no matter how long you train — try it.
  3. Hidden layer to the rescue. Two hidden neurons can carve two lines; the output neuron combines them into the non-linear region XOR needs. The decision surface becomes curved.
  4. Training = gradient descent. Each step nudges every weight a little in the direction that lowers the loss (tab 06). Watch the loss curve fall and the boundary snap into place.
    Historically this exact problem stalled neural-network research for years — until back-propagation made training hidden layers practical.
05 · Gradient-based learning

Gradient descent & loss functions

Learning is just rolling downhill on an error surface. The loss measures how wrong the model is; the gradient points uphill, so we step the opposite way. Too big a step and you fly off the cliff.

Roll downhill

the ball steps downhill by −(learning rate)×gradient · crank the rate up to watch it diverge

How wrong is a prediction?

loss as the prediction varies · cross-entropy (violet) punishes confident mistakes far more than MSE (cyan)
How it works, step by step
Gradient descent
  1. The loss surface. Plot the error as a function of a weight. Learning means finding the lowest point.
  2. The gradient. The slope at your current point tells you which way is uphill. Step the opposite way: w ← w − η · ∂Loss/∂w where η is the learning rate.
  3. Learning rate matters. Too small → painfully slow. Too large → you overshoot and the loss explodes. There's a sweet spot.
Loss / error functions
  1. MSE (mean squared error) (y−t)² — for regression; gentle, symmetric.
  2. Cross-entropy −[t·log y + (1−t)·log(1−y)] — for classification; it shoots to infinity when the model is confidently wrong, giving a strong learning signal.
06 · How the weights update

Back-propagation

Back-prop is just the chain rule applied efficiently: run forward to get the error, then send it backwards, multiplying local gradients to find how each weight should change. Step through it on a tiny network.

Tiny net: x → h → y

How it works, step by step
  1. Forward. Compute the hidden value h = σ(w₁x + b₁), the output y = σ(w₂h + b₂), and the loss L = ½(y − t)².
  2. Backward = chain rule. To know how the loss changes with a weight, multiply the local gradients along the path. For the output weight: ∂L/∂w₂ = (y − t) · y(1−y) · h
  3. Keep going. Push the signal one layer deeper (this is where the "back" happens): ∂L/∂w₁ = (y − t) · y(1−y) · w₂ · h(1−h) · x
  4. Update. Nudge every weight against its gradient: w ← w − η · ∂L/∂w. Repeat forward → backward → update thousands of times and the network learns.
    The magic of back-prop is efficiency: it reuses shared sub-computations so one backward pass gets the gradient for every weight at once.

How it works, step by step
Choosing hidden units (capacity)
  1. Capacity is how flexible a model is — roughly, how many hidden units / layers it has. More units = more wiggly functions it can represent.
  2. Underfitting. Too little capacity and the model can't even fit the training data — it's too simple (a nearly straight line through a curve).
  3. Overfitting. Too much capacity and the model bends to hit every noisy point, memorizing instead of generalizing — great on training data, poor on new data.
  4. The sweet spot. Enough capacity to capture the real pattern, not so much that it chases noise. Regularization, more data, and early stopping help push that balance.
Libraries & platforms
  1. Frameworks (PyTorch, TensorFlow, Keras, JAX) give you autograd — automatic back-propagation — plus GPU acceleration and prebuilt layers, so you describe the network and they handle the calculus.
  2. Platforms. Training runs on GPUs/TPUs; Google Colab gives free GPU access in the browser, and cloud providers offer bigger clusters for larger models.
